卑弥呼と受験対策 — 111人対応 完全版 (2026-11-04)

このZIPの chat-with-himiko-main フォルダ直下を、既存「chat-with-himiko」リポジトリに上書き・追加してください。元のindex.html、API、画像、グループ画面を含みます。

【今回の変更】
・現在のNekoponの有効人物111人を統合。旧87人＋新44人−表示対象外20人
・既存の卑弥呼アプリの名称・月アイコン・紫色の見出し・ヒーロー帯を維持
・人物イラスト(表示用WebP／グループ画像PNG)、経歴、あいさつ、質問候補、会話用の人物設定、受験向け会話ルールを移行
・新しい検索・時代/地域/人物/その他の絞り込み、プロフィール、履歴保存、複数バブル、送信・既読、グループチャットを移行
・会話APIは /api/himiko-chat を利用。互換用に /api/chat も最新版としています
・人物イラストは実際に画面が読み込むWebPを全員分同梱。元の高解像度PNGは表示に使用されず、元のNekopon ZIPに保存されているため、本ZIPには入れません。
・追加した本人像のあるアイコンがない時は絵文字を表示

【必要な本番設定】
ANTHROPIC_API_KEY（必須：会話を送る際のAPIキー）。任意で ANTHROPIC_MODEL。
高度なサーバー受信・端末へのプッシュ通知を利用する場合、Redis、VAPID、CRON_SECRET等の外部設定と1分間隔の定期実行が別途必要です。ZIPだけでバックグラウンド配信が始まることはありません。グループチャットでの通常会話はその設定なしで利用できます。
web-push 依存は package.json に含みます。

【注意】
・実際のAnthropicへのリクエスト、iPhone実機でのアニメーション、通知配信はこの場で本番確認できていません。
・既存のVercelの環境変数は維持してください。新しいURLやAPIキーの入力はHTML内に不要です。
・過去の履歴は同一ドメイン・同一端末のIndexedDBに保持されます。
・旧アプリにグループチャットがなかったため追加した画面と人物選択の状態は新規です。
